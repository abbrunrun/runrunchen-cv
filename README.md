## 免费发布方式：Netlify Drop

1. 解压这个 zip 文件
2. 打开 Netlify Drop
3. 把整个 runx2-cv-website-styled 文件夹拖进去
4. 系统会自动生成一个公开网页链接

## 免费发布方式：GitHub Pages

1. 新建 GitHub repository
2. 上传 index.html 和 style.css
3. 进入 Settings → Pages
4. 选择 main branch
5. 等待生成 github.io 免费链接
